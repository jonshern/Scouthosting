# Fonts

Bundled with the app so a build never needs the network. Latin subset,
variable weight where the family has it.

| File | Family | From |
|---|---|---|
| `inter-tight-latin-wght-normal.woff2` | Inter Tight | `@fontsource-variable/inter-tight` 5.3.0 |
| `source-serif-4-latin-wght-normal.woff2`, `-italic.woff2` | Source Serif 4 | `@fontsource-variable/source-serif-4` 5.3.1 |
| `jetbrains-mono-latin-400-normal.woff2` | JetBrains Mono | `@fontsource/jetbrains-mono` 5.3.0 |

All three are under the SIL Open Font License 1.1, which allows
bundling them with software.
