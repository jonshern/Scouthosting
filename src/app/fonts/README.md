# Fonts

Bundled with the app so a build never needs the network. Variable weight.

| File | Family | From |
|---|---|---|
| `geist-latin-wght-normal.woff2` | Geist | `geist` 1.4.2 (`dist/fonts/geist-sans/Geist-Variable.woff2`) |
| `geist-mono-latin-wght-normal.woff2` | Geist Mono | `geist` 1.4.2 (`dist/fonts/geist-mono/GeistMono-Variable.woff2`) |

Both are under the SIL Open Font License 1.1, which allows bundling
them with software. They're the suite's Modern Clean faces, shared with
Waypoint (Lantern uses Lexend for Emmett's reading rules).
